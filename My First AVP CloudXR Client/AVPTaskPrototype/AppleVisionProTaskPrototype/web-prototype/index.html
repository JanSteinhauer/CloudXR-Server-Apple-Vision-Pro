AR Window Prototypes

Browser-runnable mock-ups of the six experimental tasks (Rounds A & B × three task types). Each page renders the visionOS-style spatial window, the life-size avatar to its left, and the scripted live-caption flow exactly as described in the task-design documents in task_designs/. Use the toggle to switch between the Manager Clone and Generic Agent conditions — both share the same window structure; only the avatar, voice register, and script differ.

╔════════════════════════════════════════════════════════════════════════════╗
║                              Data Flow                                      ║
╚════════════════════════════════════════════════════════════════════════════╝

1. User Input:
   User types query in Vision Pro app → Taps send button

2. Send Query:
   QueryView → CloudXRQueryService.sendQuery()
   → FirestoreREST.createDocument()
   → HTTPS POST to Firebase
   → New document created in cloudxr_queries collection

3. Backend Processing:
   Backend listens to Firestore
   → Detects new query (status: "pending")
   → Processes query (calls LLM/API/etc)
   → Updates document with response (status: "completed")

4. Receive Response:
   CloudXRQueryService polls every 2 seconds
   → FirestoreREST.listDocuments()
   → HTTPS GET from Firebase
   → Updates @Published var queries
   → SwiftUI automatically refreshes UI
   → User sees response in app! 🎉


╔════════════════════════════════════════════════════════════════════════════╗
║                          Query Lifecycle                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

pending 🕐      Created in Firebase, waiting for backend
    ↓
processing ⏳   Backend picked it up, working on it
    ↓
completed ✅    Response ready, displayed to user
    or
failed ❌      Error occurred during processing

├── Polls for updates

├── Makes HTTPS calls to Firebase
